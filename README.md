# Cloud IaaS Orchestrator ☁️

Hi! 👋  
This repository contains a **hands-on private cloud project** that I’ve been building as part of my Cloud Computing learning path.

The main goal of this project is to **understand how cloud infrastructure works from an operations perspective**: provisioning virtual machines, managing Linux servers, configuring virtual networks and automating repetitive tasks.

This is not a production-grade cloud, but a **learning-focused environment** designed to simulate real-world **Cloud Operations**

---

## 🎯 What is this project about?
In this project, I designed and implemented a **private IaaS-style cloud lab**, where I can:

- Create and manage virtual machines on Linux
- Configure isolated virtual networks using VLANs
- Validate connectivity and service availability
- Automate basic infrastructure tasks
- Practice troubleshooting and operational workflows

---

## 🧱 High-Level Architecture
- **Hypervisor:** QEMU / KVM  
- **Virtual Networking:** Open vSwitch  
- **Network Segmentation:** VLANs  
- **Operating System:** Linux  
- **Automation:** Python & Bash  

This setup helps me understand how different infrastructure components interact in a cloud environment.

---

## 🛠️ Technologies Used
- Linux

## 🧠 Cloud Operations Focus
